# Benjamin's Portfolio

A single-page personal portfolio website built using HTML, CSS, and JavaScript.

## Live Demo

https://github.com/benjaminkitema77-cyber/portfolio-fake.git

## Features

- Personal portfolio header and navigation
- Testimonials rendered dynamically using JavaScript
- Project cards rendered dynamically using JavaScript
- Contact section with email and GitHub links
- Responsive design for desktop and mobile devices
- Smooth navigation between sections

- HTML5
- CSS3
- JavaScript
